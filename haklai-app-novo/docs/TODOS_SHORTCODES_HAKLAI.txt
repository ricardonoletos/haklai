📊 DETALHES DE CADA SHORTCODE
══════════════════════════════════════════════════════════════════════════════


1️⃣  DASHBOARD
─────────────────────────────────────────────────────────────────────────────
SHORTCODE:
  [Haklai_dashboard]

USO:
  Criar página → Adicionar shortcode → Publicar

ATRIBUTOS:
  Nenhum atributo customizável

EXEMPLO:
  [Haklai_dashboard]

QUEM VÊ:
  ✅ Todos os líderes e pastores
  ❌ Membros comuns


2️⃣  CHECKPOINT (Controle de Presença)
─────────────────────────────────────────────────────────────────────────────
SHORTCODE:
  [Haklai_checkpoint]

USO:
  Para marcar presença em reuniões

ATRIBUTOS:
  cell_id       → ID da célula (opcional)
  meeting_date  → Data da reunião (opcional)

EXEMPLOS:
  [Haklai_checkpoint]
  [Haklai_checkpoint cell_id="123"]
  [Haklai_checkpoint meeting_date="2025-10-13"]

QUEM VÊ:
  ✅ Líderes da célula
  ✅ Pastores e supervisores
  ❌ Membros comuns


3️⃣  CONFIGURAÇÕES ← VOCÊ PERGUNTOU SOBRE ESTE
─────────────────────────────────────────────────────────────────────────────
SHORTCODE:
  [Haklai_configuracoes]

USO:
  Página de configurações no frontend (estilo user-facing)

ATRIBUTOS:
  show_license      → true/false (padrão: true)
  show_system       → true/false (padrão: true)
  show_permissions  → true/false (padrão: true)

EXEMPLOS:
  [Haklai_configuracoes]
  [Haklai_configuracoes show_license="true"]
  [Haklai_configuracoes show_system="true" show_permissions="false"]

QUEM VÊ:
  ✅ Pastor Senior (nível 4)
  ✅ Pastor Supervisor (nível 5)
  ❌ Líderes, Discipuladores, Membros

NOTA IMPORTANTE:
  ⚠️  Este shortcode é para configurações no FRONTEND
  ⚠️  Para configurações de ADMIN (importar/exportar), use:
      WordPress Admin → Haklai → Configurações


4️⃣  RELATÓRIOS
─────────────────────────────────────────────────────────────────────────────
SHORTCODE:
  [Haklai_relatorios]

USO:
  Exibir relatórios de células e presenças

ATRIBUTOS:
  default_period  → Número de dias (padrão: 30)
  show_filters    → true/false (padrão: true)
  show_history    → true/false (padrão: true)

EXEMPLOS:
  [Haklai_relatorios]
  [Haklai_relatorios default_period="60"]
  [Haklai_relatorios show_filters="true" show_history="false"]

QUEM VÊ:
  ✅ Todos os líderes e pastores
  ❌ Membros comuns
