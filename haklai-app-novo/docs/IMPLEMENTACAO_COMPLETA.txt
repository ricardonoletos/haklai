📊 ESTRUTURA DE DADOS (15 Campos)
══════════════════════════════════════════════════════════════════════════════

CAMPOS DO CSV/EXCEL:

1.  tipo                 → lider ou membro (obrigatório)
2.  nome                 → Nome completo (obrigatório)
3.  email                → Email válido (obrigatório para líderes)
4.  telefone             → Formato internacional
5.  celula               → Nome da célula
6.  nivel_hierarquico    → 0-5 (0=Membro, 1=Líder, etc)
7.  habilidade           → musica, foto, teatro, etc
8.  status_batismo       → visitor, frequent_visitor, member
9.  data_batismo         → YYYY-MM-DD
10. lider_email          → Email do líder hierárquico
11. encontro_deus        → sim ou nao
12. formacoes            → ctl,cme,stp (separados por vírgula)
13. status               → active, inactive, transferred
14. foto_url             → URL da foto
15. data_criacao         → Auto-preenchido na importação


🚀 COMO USAR
══════════════════════════════════════════════════════════════════════════════

ACESSAR A PÁGINA:
─────────────────────────────────────────────────────────────────────────────
WordPress Admin → Menu Haklai → Configurações


IMPORTAR MEMBROS (4 Passos):
─────────────────────────────────────────────────────────────────────────────
1. Baixar Template CSV (botão na página)
2. Preencher com seus dados
3. Upload do arquivo
4. Aguardar e verificar resultado


EXPORTAR MEMBROS (3 Passos):
─────────────────────────────────────────────────────────────────────────────
1. Escolher filtros (opcional)
2. Selecionar formato (CSV ou Excel)
3. Clicar "Exportar Membros" → Download automático


EXEMPLO PRÁTICO - IMPORTAR 50 LÍDERES + 200 MEMBROS:
─────────────────────────────────────────────────────────────────────────────

Arquivo CSV:

🔄 FLUXOS DE FUNCIONAMENTO
══════════════════════════════════════════════════════════════════════════════

IMPORTAÇÃO (8 Etapas):
─────────────────────────────────────────────────────────────────────────────
1. Usuário seleciona arquivo
2. JavaScript valida e envia via AJAX
3. PHP valida nonce e permissões
4. Carrega arquivo (CSV ou Excel)
5. Valida estrutura e dados
6. Loop de importação (cria membros)
7. Sincronização automática (cria usuários)
8. Retorna resultado JSON

EXPORTAÇÃO (7 Etapas):
─────────────────────────────────────────────────────────────────────────────
1. Usuário define filtros e formato
2. JavaScript envia via AJAX
3. PHP valida e sanitiza filtros
4. Busca membros (WP_Query otimizada)
5. Prepara dados (resolve relacionamentos)
6. Gera arquivo (CSV ou Excel)
7. Retorna URL para download
